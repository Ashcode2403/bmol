A LITTLE WORLD FOR BATHU MOLE
=============================

This is a mobile-first static website built with HTML, CSS and JavaScript.
No backend or database is required.

RUN LOCALLY
1. Extract the ZIP.
2. Open index.html in a browser, or use VS Code Live Server.
3. Keep the assets folder beside index.html.

MUSIC
The uploaded Hona Marro MP3 is included in assets/ and wired into the player.
The player is manual: it does not autoplay.

ADD YOUR PERSONAL CONTENT
- Use "Add our photos" to preview selected photos in the current browser session.
- Upload a .txt or .md file for the first conversation / memory text.
- Upload a voice recording in the final surprise section.
- The photo and voice previews use local browser object URLs and are not uploaded to a server.
- The worry jar is intentionally private and is not sent anywhere. It clears after the comfort message.

DEPLOY TO VERCEL
1. Create a new project in Vercel.
2. Import this folder/repository.
3. Choose "Other" / no framework preset.
4. Leave build command empty and output directory as the project root.
5. Deploy.

CUSTOMIZATION
Edit the text directly in index.html. Change colours and layouts in styles.css.
